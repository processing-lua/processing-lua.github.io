Libraries

Everything available in Lua Mode out of the box.

None of these need a require. They are in every sketch from the start.

Lua's own libraries

table

Lists and maps in one. table.insert, table.remove, table.sort, table.concat.

string

Text. string.format, :sub, :find, :gsub, :upper, patterns.

math

math.floor, math.huge, math.pi and the rest. Processing's own sin(), abs() and friends work too.

utf8

Text with accents and other non-ASCII letters.

os

os.time, os.date, os.clock.

io

Reading and writing files, if loadStrings() isn't enough.

coroutine

Functions that can pause and pick up later. Handy for animations that run in steps.

Processing's classes

PVector

2D and 3D vectors: v:add(w), v:mag(), v:normalize(), and + - * / between vectors.

IntList / FloatList / StringList

Processing's lists, with sort(), shuffle(), sum() and the rest.

IntDict / FloatDict / StringDict

Processing's dictionaries.

Table / TableRow

CSV and TSV files: loadTable(), t:getRowCount(), row:getFloat("x").

JSON

loadJSONObject(), loadJSONArray() and saveJSONObject(). JSON comes in as plain Lua tables.

XML

loadXML(), xml:getChildren("item"), xml:getString("name").

PImage / PGraphics

Images and off-screen layers: img:get(x, y), img.pixels, pg:beginDraw().

PShape / PFont / PShader

SVG and OBJ shapes, fonts, and GLSL shaders.
