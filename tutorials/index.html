Tutorials

Lua Mode is a plugin for the Processing IDE. You write sketches in Lua inside Processing, hit Run, and a window opens. Pick the section that matches what you're trying to do.

Using Lua Mode inside the Processing IDE

Write setup() and draw() as Lua functions, hit Run, and see a window open. Your sketch runs on a small native runner with the same drawing engine as Rust Mode, so there is nothing to compile and it starts right away.

Sharing what you made

File > Export Application makes a folder with your sketch, its data folder and the runner, ready to run on a computer without Processing. File > Export as PDEZ packs the sketch into one file another Processing user can open.

New to all of this? Start with Getting Started, then open any of the examples. Every one of them is the Processing example you may already know, written in Lua.
