What's New

Lua Mode keeps Processing's names. The API is the one you know: setup(), draw(), ellipse(), background(), mouseX, mouseY, fill(), stroke() all work the same way. What changes is the language around them. These are the things to know.

Changed
Functions end with end

Blocks use then, do and end instead of braces, and lines don't need semicolons.

function draw()
  if mouseX > width / 2 then
    fill(255)
  else
    fill(0)
  end
end
Changed
Variables are local or global

There are no types to write. local x = 10 makes a variable for the file or the function it's in. Variables a sketch keeps between frames go at the top of the file.

Changed
Text joins with ..

+ only adds numbers. Join text with ..: text("score: " .. score, 10, 20).

Changed
Lists are tables, counted from 1

A Java array is a table: local xs = {1, 2, 3}, and xs[1] is the first one. #xs is how many there are. table.insert(xs, v) adds to the end, and for i, v in ipairs(xs) do ... end goes through them.

Processing's own indexes stay as they are in Java: pixels[], get(i) on IntList and the like are counted from 0, so the index math from Java examples still works.

Changed
Methods use a colon

Calling a method on an object uses :, as in v:add(w), img:get(x, y) or pg:beginDraw(). Fields are still read with a dot: img.width, v.x.

Changed
Classes are tables with new()

Lua has no class keyword. A class is a table with a new function, and its methods are written with a colon:

Ball = {}
Ball.__index = Ball

function Ball.new(x, y)
  local self = setmetatable({}, Ball)
  self.x, self.y = x, y
  return self
end

function Ball:display()
  ellipse(self.x, self.y, 20, 20)
end
Changed
Division doesn't round

7 / 2 is 3.5. When you want Java's whole-number division, use 7 // 2, or int().

Same
mousePressed works both ways

As in Java, mousePressed is true while the mouse is held, and function mousePressed() runs once per click. The same goes for keyPressed.

New
Two renderers

The toolbar has a renderer menu. The default draws on the CPU. libprocessing draws with Bevy and wgpu on your graphics card, with real 3D lights and shaders.
